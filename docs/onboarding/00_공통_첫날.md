목표: **모두가 같은 환경에서 실행되고, PR 한 번을 직접 해보는 것.** 코딩은 아직 안 함.

| # | 할 일 | 확인 |
| --- | --- | --- |
| 1 | GitHub 초대 메일 수락 (또는 github.com 알림) | 저장소가 보임 |
| 2 | Git, Node 20+, pnpm 설치 (`npm i -g pnpm`) / 백엔드·ML은 uv도 | `git --version`, `pnpm -v` 동작 |
| 3 | `git clone https://github.com/CoSunny-713/LG-Tune.git` → `cd LG-Tune` → `pnpm install` → `pnpm setup` | 에러 없음 |
| 4 | `pnpm dev:mock` → http://localhost:5173 | 화면에 "연결됨"과 AI 친구 말풍선이 뜸 |
| 5 | **첫 PR 연습** (아래) | PR이 main에 합쳐짐 |
| 6 | 내 역할 문서 읽기: 프론트 `01_프론트.md` / AI `02_AI.md` | |

## 첫 PR 연습 (협업 흐름을 손에 익히기)
```bash
git switch -c chore/team-내이름          # 1. 내 브랜치 만들기
# 2. docs/TEAM.md 표에 내 줄 추가하고 저장
git add docs/TEAM.md
git commit -m "chore: 팀원 추가 (내이름)"
git push -u origin chore/team-내이름     # 3. GitHub에 올리기
```
4. GitHub 저장소 페이지에 뜨는 **Compare & pull request** 클릭 → 생성
5. 자동 검사 초록불 확인 → 본인이 **Squash and merge**
6. 내 컴퓨터 최신화: `git switch main && git pull`

> 막히면: 에러 메시지 전체를 복사해서 팀 단톡이나 Claude/Codex에 붙여넣기. **API 키·비밀번호는 절대 붙여넣지 않기.**

## 매일 작업 흐름 (이것만 반복)
```
git switch main && git pull          ← 아침: 최신 받기
git switch -c feat/fe-편성표          ← 작업 브랜치
(작업 → git add → git commit)        ← 여러 번 해도 됨
git push -u origin feat/fe-편성표     ← 올리기 → PR 생성
```
