# AI(모델 학습) 담당 가이드

## 한 줄 요약
**모델 2개를 학습해서 정해진 모양(ONNX + 아래 입출력)으로 넘긴다.** 백엔드는 이 모양만 보고 붙인다.

## 백엔드와의 약속 (이 모양만 지키면 됨)
### 호출어
- 파일: `wakeword.onnx`
- 입력: 16kHz 모노 음성, 80ms(1280샘플) 단위로 계속 들어옴
- 출력: 0~1 점수 (임계값은 `MODEL_CARD.md` 에 적기)

### 응/아니
- 파일: `yesno.onnx` + `tokenizer/` 폴더
- 입력: STT 결과 문장 1개 (예: "어 그래 틀어", "됐다 고마", "이따가")
- 출력: 4개 확률 `{"yes", "no", "unsure", "other"}` (합 1)

## 산출물 체크리스트
- [ ] `ml/<모델>/train.ipynb` (Colab에서 돌린 노트북)
- [ ] `ml/<모델>/eval.py` — **고정 평가셋**으로 점수 출력 (평가셋은 처음에 정하고 바꾸지 않기)
- [ ] `ml/<모델>/MODEL_CARD.md` — 데이터, 학습 설정, 점수, 한계
- [ ] `.onnx` 파일은 GitHub **Releases** 에 업로드 → `models/manifest.json` 에 버전·주소·sha256 기록
