# 프론트엔드 담당 가이드

## 한 줄 요약
**백엔드를 기다리지 않는다.** `pnpm dev:mock` 으로 가짜 서버가 시연 시나리오대로 이벤트를 보내주니, 그걸 받아 화면을 만든다.

## 내 폴더
`frontend/` 만 고친다. (React + Vite + TypeScript)

| 경로 | 내용 | 고쳐도 되나 |
| --- | --- | --- |
| `frontend/src/` | 화면 코드 | ✅ |
| `frontend/mock/ws-replay.mjs` | 가짜 서버 | ✅ (필요하면) |
| `frontend/src/shared/api/*.ts` | 백엔드 계약에서 **자동 생성된 타입** | ❌ (`pnpm gen` 으로만) |
| `contracts/`, `backend/` | 계약·서버 | ❌ → 바꿔야 하면 이슈에 `contract` 라벨 |

## 화면이 받는 이벤트 (서버 → 화면)
| type | 화면 동작 |
| --- | --- |
| `clock.tick` | 화면 시계 |
| `plan.updated` | 오늘 편성표 오버레이 |
| `buddy.nudge` | **조용한 아이콘**만 구석에 (소리 X, 15초 후 사라짐) |
| `buddy.say` | AI 친구 말풍선 + 음성 재생 |
| `listen.open` / `listen.close` | "듣는 중" 표시 |
| `asr.final` | 사용자 말을 자막처럼 잠깐 표시 |
| `playback.switch` | 채널 전환 |
| `playback.duck` | TV 볼륨 낮추기/복구 |
| `tv.action` | 이지TV 기능 실행 흉내 (영상통화 화면, 글자 크게, 밝기 등) |
| `card.show` / `card.hide` | 인물관계도·구절·공연 카드 |
| `metrics.snapshot` | 대시보드 |

화면이 보내는 것: `ui.ready`(접속 시), `player.state`(재생 상태·광고 구간 여부, 1초마다), `remote.press`(리모컨, 선택), `nudge.response`(아이콘 반응).
정확한 필드는 `src/shared/api/ws.ts` 타입을 그대로 쓰면 됨.

## 만들 화면 순서
1. **webOS TV 셸** — 켜면 메뉴 없이 바로 방송 + 구석에 AI 친구 (리모컨 없이도 되는 화면)
2. 가상 채널 플레이어 — 영상 + 광고 구간 표시 → `player.state.segment` 로 보고
3. AI 친구 말풍선 · 조용한 아이콘 · 듣는 중 표시
4. 편성표 오버레이 (큰 글씨, 고대비, 한 화면 3~5칸)
5. `tv.action` 흉내 화면 (영상통화, 글자 크기, 밝기, 외부입력)
6. 카드 3종 → 자녀 설정 페이지(모바일) → 1일차/7일차 비교 + 대시보드

## 시니어 화면 원칙
글자 최소 28px · 고대비 · 한 번에 하나의 메시지 · 애니메이션 최소 · 색만으로 의미 전달 금지
