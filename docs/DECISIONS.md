# 확정 결정 (최신본 · 이 문서가 v1 명세서·계획서보다 우선)

마지막 수정: 2026-11-25

## 한 줄 정의
**webOS TV에 사는 내 친구.** 같이 보고, 같이 본 걸 기억해서, 방해되지 않는 순간에 먼저 꺼낸다.

## 제품 위치
- AI 친구는 **LG TV(webOS) 안**에 산다. 셋톱은 통신사 것이 그대로 있어도 되고, 어느 셋톱이든 상관없다 → "LG TV를 사야 할 이유"
- **리모컨 없이 말로만.** 전용 버튼 없음. TV 켜면 이미 떠 있고, 어디서든 "(호출어 미정)"로 부른다. 리모컨은 쓰고 싶은 사람만(선택)
- **이지TV 기능을 말로 실행**: "큰아들한테 영상통화 걸어줘"(LG 버디), "글자 크게", "화면 밝게", "셋톱 화면으로 바꿔줘"(외부입력), "두뇌 게임 하자", "도와줘" → `tv.action` 이벤트
- 시연: 노트북 = webOS TV, 가상 채널 = 셋톱 출력 (HDCP 때문에 실제 셋톱 화면 캡처 불가)

## 핵심 기술 4개
| # | 기술 | 방식 |
| --- | --- | --- |
| 1 | 음성 순환 | 마이크 → (호출어/버튼) → STT(Whisper) → AI 두뇌(Claude) → TTS → 스피커. 들을 때 TV 볼륨 자동 낮춤(`playback.duck`). 답은 문장 단위로 바로 TTS → 첫 소리 2초 목표 |
| 2 | 기억하는 친구 | 대화·시청 기록 → 밤마다 Claude가 **기억 카드**로 정리 → v1은 카드를 통째로 프롬프트에 넣음(200개 이내). 넘치면 그때 검색 추가 |
| 3 | 편성표 | **순수 규칙 기반**: 지켜야 할 규칙(취침 등) + 가중치 점수 + 고른 이유. 밴딧 없음 |
| 4 | 말로 TV 조작 | 자주 쓰는 명령은 규칙 사전으로 즉시 실행(빠르고 확실), 애매한 말만 Claude 도구 호출로 해석. 영상통화처럼 되돌리기 어려운 건 한 번 더 확인 |

## 먼저 말걸기 규칙 (가장 조심할 부분)
| 규칙 | 내용 |
| --- | --- |
| 말해도 되는 순간 | `player.state.segment` 가 `break`(광고) 또는 `credits`(엔딩), 채널 전환 직후, 사용자가 먼저 말했을 때 |
| 금지 | 본방송(`program`) 중, 리모컨 조작 중, 잠든 것 같을 때 |
| 2단계 | 먼저 `buddy.nudge`(조용한 아이콘) → 사용자가 반응(`nudge.response: opened`)해야 `buddy.say` |
| 빈도 | 프로그램당 1회, 하루 3~5회 |
| 자동 감소 | "됐어/조용히" 또는 `dismissed` → 그날 중단, 누적되면 빈도 낮춤 |
| 예외 | 사용자가 약속한 편성 알림은 정시에 바로 말함 |

## AI 사용처 (자리마다 맞는 모델 · 원칙: 판단은 작은 모델, 말은 Claude, 끊겨도 로컬)
| 자리 | 1순위 | 예비 | 이유 |
| --- | --- | --- | --- |
| 말소리 감지 | silero-vad (로컬) | - | 가볍고 빠름 |
| 호출어 "(호출어 미정)" | **직접 학습** 경량 모델 (로컬) | 말소리 감지 + Whisper 첫 단어 확인 | 항상 켜져 있어야 해서 로컬 필수 |
| STT | faster-whisper (로컬) | - | 음성이 밖으로 안 나감 |
| 응/아니 판단 | **직접 학습** KLUE-RoBERTa (로컬) | JEV(예/아니 확률) → Claude | 수 ms, 무료. JEV는 비교 기준·라벨링에도 사용 |
| TV 명령 해석 | 규칙 사전 | JEV(선택지 판정) → Claude 도구 호출 | 자주 쓰는 명령은 즉시·확실하게 |
| 기억↔지금 프로그램 관련성 | JEV(점수) | 키워드 매칭 | 프로그램 바뀔 때마다 여러 번 하는 작은 판단 → 판단 전용 모델이 적합 |
| 대화 생성 | Claude Haiku 5.5 | Qwen 소형 (로컬) → 고정 멘트 | 말맛·공감은 Claude, 네트워크 끊기면 Qwen |
| 기억 정리 (밤) | Claude Sonnet 5.5 | Qwen 로컬 | 품질 중요, 실시간 아님 |
| TTS | Supertonic 또는 자체 TTS | 고정 멘트 음성 캐시 | |

후보 확인 필요: JEV는 신규 가입이 중단된 적이 있어 **계정 확보 먼저**(안 되면 직접 학습 모델 + 규칙으로 대체). Qwen은 소형 모델의 한국어 품질·노트북 속도 테스트 후 버전 확정(라이선스는 버전별 확인).
