# 0단계 약속: DB · API · 공통 샘플 (초안)

> 마이모드 개발 정리(@연상, 11/26) 기준. **바꾸려면 PR로, 3명 모두 확인.**
> 원본 코드: DB = `backend/app/models/db.py` · API 모양 = `backend/app/contracts/rest.py`

## 1. 시간 표기
- 전부 **한국 시간**, 시간대 표기 없이 `2026-12-01T20:30:00`
- 시연 기준일: **2026-12-01(화)**. 시청 기록은 그 전 14일 (11/17~11/30)

## 2. DB 표 (SQLite + SQLAlchemy)
| 표 | 한 줄 = | 주요 칸 | 채우는 사람 |
| --- | --- | --- | --- |
| `channels` | 채널 | `id`(예: KBS1), `number`(리모컨 번호), `name` | A |
| `programs` | 방송 한 편 | `channel_id`, `title`, `series_key`(회차 묶음), `genre`, `start`, `end`, `cast`, `is_new`(새 회차), `is_live`(생방송) | A |
| `lg_contents` | 빈 시간용 LG채널·VOD | `title`, `genre`, `cast`, `duration_min`, `source`(LG채널/LG VOD) | A |
| `seniors` | 어르신 한 명 | `age`, `wake_time`, `sleep_time`, `pref_source`(child/self/age_default), `seed_prefs`({series, cast, genres}), `family_picks` | A (가족 화면) |
| `watch_logs` | 시청 기록 한 건 | `senior_id`, `series_key`, `genre`, `cast`, `channel_id`, `started_at`, `watched_min`, `how_started`(chosen/continued/plan), `cancelled`, `feedback`(기록용) | C (TV 화면) |
| `user_rules` | 음성 명령으로 생긴 규칙 | `kind`(exclude/pin/skip_today/rest_day), `target_type`(series/genre/none), `target`, `date`, `from_time`, `active` | B (음성 명령 API) |
| `plan_items` | 하루표 한 칸 | `senior_id`, `date`, `program_id`, `score`, `reason`, `kind`(pick/fill/lg) | B |

- `how_started`: chosen = 직접 고름(말로 "KBS 틀어 줘" 포함) / continued = 앞 방송에서 그냥 이어짐 / plan = 하루표 추천으로 봄
- `pref_source` 우선순위: 자녀 입력(child) > 본인 선택(self) > 나이대 기본값(age_default)

## 3. 공통 샘플 (`data/sample/`)
| 파일 | 내용 |
| --- | --- |
| `channels.json` | 채널 6개 (번호는 예시) |

| `lg_contents.json` | LG채널·VOD 14개 (20~60분) |

| `watch_logs.json` | 14일치 시청 기록. 5분 미만, 틀어만 놓은 긴 기록(continued), 추천으로 본 기록(plan) 포함 |

- 다시 만들기 `cd backend && uv run python scripts/make_sample.py` · 개발 DB에 넣기 `pnpm sample`

## 4. 음성 명령 (리모컨 = 폰, 마이크 버튼 누르고 말하기)
| 어르신 말 (예) | 명령 | 엔진 처리 | 확인 질문 |
| --- | --- | --- | --- |
| "다른 거 틀어 줘" | `skip_today` | 지금 방송을 오늘만 빼고 하루표 다시 계산 | 없음 |
| "이거 이제 안 볼래" | `exclude` | **앞으로 절대 안 넣음** (점수 아님, 규칙) | 있음 |
| "이거 매일 챙겨 줘" | `pin` | 항상 넣음 | 있음 |
| "오늘은 그만 볼래" | `rest_day` | 지금 시각 이후 오늘 하루표 비움 | 없음 |
| "방금 거 취소" | `undo` | 마지막 규칙 끄기 (학습에서도 제외) | 없음 |
| "KBS 틀어 줘" | `change_channel` | 채널 이동 (직접 고른 시청으로 기록) | 없음 |
| 그 외 | `question` | 답하는 에이전트로 (다음 단계) | — |

## 5. API
| 요청 | 응답 | 담당 |
| --- | --- | --- |
| `GET /api/schedules/{senior_id}?date=YYYY-MM-DD` | `ScheduleResponse` = `{senior_id, date, items: [ScheduleItem]}` | B |
| `POST /api/commands` | 음성 명령 해석·실행 결과 (`CommandResponse`) | B |

`ScheduleItem`: `program_id, channel_id, channel_number(LG 콘텐츠는 없음), title, start, end, score, reason, kind(pick|fill|lg)` — 시작 시각 순, 서로 안 겹침, 기상~취침 안.

## 6. 하루표 엔진 규칙 (6개만. 숫자는 `backend/app/engine/config.py` 한 곳에)
| # | 규칙 |
| --- | --- |
| 1 | **점수** = 0.30 시리즈 + 0.25 출연자 + 0.15 장르 + 0.15 시간대 습관 + 0.10 새 회차·생방송 + 0.05 가족 추천 |
| 2 | **신호 세기**: 직접 고름 100% · 이어짐/추천으로 봄 30% · 5분 미만·취소 0% (틀어만 놓기, 추천만 보다 좁아지기 방지) |
| 3 | **본 날 기준 반감기**: TV를 본 날 14일 (매일 보는 분·주말만 보는 분 공평). 60일 넘은 기록은 버림. 기록이 적으면 첫날 정보 비중↑ (기록 비중 = 횟수 ÷ (횟수 + 10)) |
| 4 | **음성 명령은 규칙**: exclude는 절대 제외(채우기·LG 포함), pin은 항상 포함, skip_today·rest_day는 그날만 |
| 5 | **배치(DP)**: 기상~취침 안, 점수 0.35 이상, "점수 × 방송 길이" 합이 최대가 되게 겹치지 않게 |
| 6 | **빈 시간**: 20분 미만이면 앞 채널 그대로(fill), 20분 이상이면 들어가는 LG채널·VOD 중 점수 최고(lg). 맞는 게 없으면 비워 둠 |
