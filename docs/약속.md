# 0단계 약속: DB · API · 공통 샘플 (초안)

> 마이모드 개발 정리(@연상, 11/26) 기준. **바꾸려면 PR로, 3명 모두 확인.**
> 원본 코드: DB = `backend/app/models/db.py` · API 모양 = `backend/app/contracts/rest.py`

## 1. 시간 표기
- 전부 **한국 시간**, 시간대 표기 없이 `2026-12-01T20:30:00`
- 시연 기준일: **2026-12-01(화)**. 시청 기록은 그 전 14일 (11/17~11/30)

## 2. DB 표 (SQLite + SQLAlchemy)
| 표 | 한 줄 = | 주요 칸 | 채우는 사람 |
| --- | --- | --- | --- |
| `channels` | 채널 | `id`(예: KBS1), `number`(리모컨 번호), `name` | A |
| `programs` | 방송 한 편 | `channel_id`, `title`, `series_key`(회차 묶음), `genre`(대표 장르), `genres`(장르 전부, 비면 `[genre]`), `start`, `end`, `cast`(모르면 `[]`), `is_new`(새 회차), `is_live`(생방송) | A |
| `lg_contents` | 빈 시간용 LG채널·VOD | `title`, `genre`, `cast`, `duration_min`, `source`(LG채널/LG VOD) | A |
| `seniors` | 어르신 한 명 | `age`, `wake_time`, `sleep_time`, `pref_source`(child/self/none), `seed_prefs`({series, cast, genres}), `family_picks` | A (가족 화면) |
| `watch_logs` | 시청 기록 한 건 (**이 기기 안에서만 씀**) | `senior_id`, `series_key`, `genre`, `genres`, `cast`, `channel_id`, `started_at`, `watched_min`, `how_started`(chosen/continued/plan), `cancelled`, `feedback`(기록용) | C (TV 화면) |
| `user_rules` | 음성 명령으로 생긴 규칙 | `kind`(exclude/pin/skip_today/rest_day), `target_type`(series/genre/none), `target`, `date`, `from_time`, `active` | B (음성 명령 API) |
| `plan_items` | 하루표 한 칸 | `senior_id`, `date`, `program_id`, `score`, `reason`, `kind`(pick/fill/lg) | B |

- `how_started`: chosen = 직접 고름(말로 "KBS 틀어 줘" 포함) / continued = 앞 방송에서 그냥 이어짐 / plan = 하루표 추천으로 봄
- `pref_source` (첫날 관심사 출처) 우선순위: 자녀가 설치 때 부모님 관심사를 고름(child) > 본인이 고름(self) > 없음(none). **기본 장르는 두지 않는다** (관심사도 기록도 없으면 새 회차·생방송 + 시청 시간대만으로 짬)
- **시청 기록은 이 기기 안에서만 쓴다** (취향 추정·하루표 계산용. 밖으로 보내지 않음)

- 방송 이름·출연자는 **전부 가상**. 실제 편성표는 A가 1단계에서 넣음
- 다시 만들기 `cd backend && uv run python scripts/make_sample.py` · 개발 DB에 넣기 `pnpm sample`
- DB 구조(`models/db.py`)가 바뀌면 옛날 DB 파일로는 하루표가 안 나옴 → `pnpm sample` 한 번 (화면에 안내 문구가 나옴)

## 4. 음성 명령 (리모컨 = 폰, 마이크 버튼 누르고 말하기)
| 어르신 말 (예) | 명령 | 엔진 처리 | 확인 질문 |
| --- | --- | --- | --- |
| "다른 거 틀어 줘" | `skip_today` | 지금 방송을 오늘만 빼고 하루표 다시 계산 | 없음 |
| "이거 이제 안 볼래" | `exclude` | **앞으로 절대 안 넣음** (점수 아님, 규칙) | 있음 |
| "이거 매일 챙겨 줘" | `pin` | 항상 넣음 | 있음 |
| "오늘은 그만 볼래" | `rest_day` | 지금 시각 이후 오늘 하루표 비움 | 없음 |
| "방금 거 취소" | `undo` | 마지막 규칙 끄기 (학습에서도 제외) | 없음 |
| "KBS 틀어 줘" | `change_channel` | 채널 이동 (직접 고른 시청으로 기록) | 없음 |
| 그 외 | `question` | 답하는 에이전트로 (다음 단계) | — |

## 5. API
| 요청 | 응답 | 담당 |
| --- | --- | --- |
| `GET /api/schedules/{senior_id}?date=YYYY-MM-DD` | `ScheduleResponse` = `{senior_id, date, items: [ScheduleItem]}` | B |
| `POST /api/commands` | 음성 명령 해석·실행 결과 (`CommandResponse`) | B |

`ScheduleItem`: `program_id, channel_id, channel_number(LG 콘텐츠는 없음), title, start, end, score, reason, kind(pick|fill|lg)` — 시작 시각 순, 서로 안 겹침, 기상~취침 사이에 **시작** (끝은 취침 뒤여도 됨).

## 6. 하루표 엔진 규칙 (숫자는 `backend/app/engine/config.py` 한 곳에. 합격 기준·우선순위는 `backend/app/engine/QUALITY.md`)
| # | 규칙 |
| --- | --- |
| 1 | **점수** = 0.30 시리즈 + 0.25 출연자 + 0.15 장르 + 0.15 시간대 습관 + 0.10 새 회차·생방송 + 0.05 가족 추천. 장르 = 장르 목록 중 가장 좋아하는 것. **출연자 정보가 없으면** 출연자 칸 = 0 (모르는 출연자와 같음, `MISSING_CAST_SCORE`) |
| 2 | **신호 세기**: 직접 고름 100% · 이어짐/추천으로 봄 30% · 5분 미만·취소 0% (틀어만 놓기, 추천만 보다 좁아지기 방지) |
| 3 | **본 날 기준 반감기**: TV를 본 날 14일 (매일 보는 분·주말만 보는 분 공평). 장르가 여러 개인 기록은 각 장르에 같은 무게. 60일 넘은 기록은 버림. 기록이 적으면 첫날 관심사 비중↑ (기록 비중 = 횟수 ÷ (횟수 + 10)). 관심사를 바꾸면 다음 하루표에 바로 반영 |
| 4 | **음성 명령은 규칙**: exclude는 절대 제외(채우기·LG·새로 추천 포함, 장르로 뺐으면 장르 목록 중 하나라도 맞으면 제외), pin은 항상 포함(시청 시간대 밖이어도. 먼저 넣고 그 시간만큼 시간 상한에서 뺌. pin끼리 겹치면 점수 높은 쪽), skip_today·rest_day는 그날만 |
| 5 | **배치(DP)**: 기상~취침 사이에 **시작**하는 방송(끝나는 시간 무관), 점수 0.35(기준점) 이상, 하루 시간 상한 안에서 "(점수 − 기준점) × min(방송 길이, 60분)" 합이 최대가 되게 겹치지 않게. **같은 시리즈는 하루 1번**. **예외**: 0.35 를 넘는 방송이 6개 미만이면 기준점을 6등 점수까지 낮춤 (첫날에도 하루표가 비지 않게) |
| 6 | **빈 시간**: 방송 사이 — 20분 미만이면 앞 채널 그대로(fill, 같은 시리즈면 비움), 20분 이상이면 LG채널·VOD. **하루 첫 시청 구간 시작~첫 방송**도 빈 시간. 시청 시간대 밖에서 시작하면 채우지 않음. LG 는 취향 점수 ≥ 기준점×0.8, 하루표 전체 시간의 30% 이하, 배정 순서 = 새로 추천 → 첫 시청 구간 → 점수순 |
| 7 | **시청 시간**: 시청 시간대 = 시간대 습관 점수 0.35 이상인 시간대 — pick 은 그 안에서 **시작**하는 것만. 하루 pick 총 시간 ≤ 최근 14일 **직접 고른(chosen)** 시청이 있던 날의 평균 (그런 날이 7일 미만이면 240분) |
| 8 | **오늘의 대표 방송**: 시리즈 취향 1위(0.5 이상)의 새 회차가 시청 시간대 안에 있으면 먼저 넣음. 이유 "오늘 꼭 챙겨 보실 ○○ 새 회차예요". 시간 상한엔 포함, 장르 비율엔 제외 |
| 9 | **다양성**: 한 장르 ≤ max(50%, 그분 실제 시청 비율) (대표 방송·챙겨 줘 제외, 셀 칸 2개 이상일 때), 같은 장르 3연속 없음 — 넘치면 그 장르·그 줄의 배치 무게를 ×0.7 하고 다시 배치(최대 10번) |
| 10 | **채널 유지**: 앞 칸과 같은 채널에 거의 비슷한 방송이 있으면 그걸로 (점수 +0.05 가산해 비교) |
| 11 | **새로 추천 1칸**: 가장 좋아하는 장르와 가까운 장르(`NEAR_GENRES`) 중 시청 기록상 거의 안 본(5% 미만) 장르. 배치 뒤 남은 시간·자리에 방송, 없으면 빈 시간의 LG (이 LG 1개는 취향 점수 기준 예외). 이유 "새로 추천해 드려요 — …" |
| 12 | **취향을 모를 때**(관심사·기록 둘 다 없음): 새 회차·생방송만, 이유 "아직 취향을 몰라서 새로 하는 방송 위주로 골랐어요" |
