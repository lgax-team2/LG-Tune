# ml/ — 직접 학습하는 모델

## 호출어 "(미정)" (`wakeword/`) — P0
| 항목 | 내용 |
| --- | --- |
| 이유 | 리모컨 버튼 없이 음성으로만 부르므로 필수 |
| 데이터 | TTS로 여러 목소리·속도의 "(호출어 미정)" 합성 + 팀원 녹음 + 방송 소리(오작동 방지용 음성 없는 예시) |
| 합격 기준 | 재현율 90%, TV 켜둔 상태 오작동 시간당 0.5회 미만 (12/4) |
| 미달 시 | 말소리 감지 + Whisper로 첫 단어(호출어) 확인 |
| 참고 | TV 소리는 우리가 재생하므로 원본 소리를 알고 있음 → 에코 제거로 TV 소리를 빼고 들을 수 있음 |

## 응/아니 분류기 (`yesno/`)
| 항목 | 내용 |
| --- | --- |
| 입력 | STT로 바뀐 짧은 문장 (예: "어 그래 틀어", "됐다 고마", "이따가") |
| 출력 | `yes` / `no` / `unsure` / `other` 4분류 |
| 모델 | KLUE-RoBERTa-base 미세조정 → ONNX 내보내기 |
| 데이터 | 팀이 만든 시니어 말투 문장 + LLM으로 늘린 변형. 평가셋은 처음에 고정하고 바꾸지 않음 |
| 합격 기준 | 실제 녹음 문장 기준 F1 0.9 (12/5) |
| 미달 시 | 규칙 사전 + Claude 판정으로 대체 |

- 완성된 `.onnx` 는 GitHub Releases 에 올리고 `models/manifest.json` 에 버전·해시 기록
