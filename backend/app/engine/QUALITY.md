## 가치 지표 (확인 화면 맨 위, 합격 판정 아님)
- 취향 일치율: 이유가 취향 근거(시리즈·출연자·장르·시간대·대표 방송)인 칸 비율. "새로 추천"·"채널 유지" 칸은 분모에서 뺌 (취향으로 고른 칸이 아님)
- 새 장르 발견: "새로 추천" 칸의 장르
- LG 노출: 분 · 비율
- 장르 비율: 대표 방송 포함 / 제외 둘 다

## 해석 (결정 기록은 PLAN.md "결정 기록")
- M2 "챙겨 줘 100%" = 기상~취침 사이에 시작하고, 겹치는 챙겨 줘끼리는 점수 높은 쪽(같으면 시작 시각→ID 순)으로 정한 뒤 그 전부. 빠진 챙겨 줘는 확인 화면에 이유 표시
- M5 이유 근거: 시리즈 = 시리즈 취향 > 0 / 출연자 = 그 사람이 방송에 나오고 취향 > 0 / 장르 = 방송 장르 목록에 있고 취향 > 0 / 시간대 = 그 시간대 습관 > 0 / 새 회차·생방송 = 표시가 실제로 있음 / 가족 추천 = 가족 추천 목록에 있음
- S1 "시리즈 취향 1위" = 전체 시리즈 취향 1위(점수 0.5 이상)가 오늘 시청 시간대 안에서 새 회차를 할 때만. 없으면 "해당 없음"
- S2 실제 시청 비율 = chosen 시청 기록의 시간 중 그 장르(대표 장르) 비율
- S6 = (v4) 기상 이후 처음으로 켜짐 '높음'이 되는 시각. '높음'이 없으면 "해당 없음"
- S5 "여유" = 켜짐 '높음·중간' 빈자리에 가장 짧은 LG 하나라도 들어갈 자리·하루 시간·LG 칸 수(S10)가 남음. 여유가 있었는데 장르 비율·3연속 때문에 못 넣으면 실패
- S7 = 출연자 정보가 없으면 출연자 항목을 빼고 나머지 가중치 합(0.75)으로 나눠 계산 (11/27 v3.1: ±0.02 기준이 잘못돼 바꿈)
- 점수(무게)가 같으면 시작이 이른 방송 먼저 (DP·후보 정렬 모두)
- S9 비율 = LG 시간 ÷ 하루표 전체 시간(방송 + 채널 유지 + LG)
- TV 켜짐 패턴 (11/27 v3.2): 시(hour)마다 켜짐 비율 = 최근 14일 중 기록 있는 날의 평균으로 그 1시간 중 켜져 있던 분/60 (겹친 기록은 한 번). 높음 ≥ 0.6 / 중간 ≥ 0.25 / 낮음. 빈 시간: 높음 = 배경 편성(앞 채널 이어서, 없으면 그 시각에 평소 켜 두는 채널, 남은 자리는 취향 LG) / 중간 = 20분 이하 / 낮음 = 쉬는 시간(확인 화면 표시)
- 방송의 켜짐 단계 = 걸친 시각 중 가장 높은 단계. 예산이 모자라면 '높음'에 걸친 방송부터 배치
- '틀어만 놓기' 기록만 있는 시리즈는 방송 칸이 아니라 배경 편성 후보
